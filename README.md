# 📝 YouTube Timestamped Markdown Notebook

A lightweight, high-performance Chrome Extension (Manifest V3) for taking timestamped Markdown notes and instant video bookmarks while watching technical talks, lectures, and coding tutorials on YouTube.

---

## 🌟 Key Features
- ⏱️ **Instant Timestamping**: Press `Alt + N` or click the floating button to auto-insert the video's current playback timestamp (`[MM:SS]`).
- 📝 **Markdown Note Drawer**: Sleek side drawer matching YouTube's dark UI for taking rich structured notes.
- ▶️ **1-Click Video Jump**: Click any timestamp badge in your notebook to jump directly to that exact moment in the video.
- 📥 **Export to Markdown**: 1-click export of all video notes to `.md` files formatted with clickable YouTube timestamp links.
- ☁️ **Chrome Storage Sync**: Automatically syncs notes across your devices.

---

## 🚀 Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/giridharpatil333/youtube-timestamped-markdown-notebook.git
   ```
2. Open Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `extensions/youtube-timestamped-markdown-notebook` directory.
5. Open any [YouTube](https://www.youtube.com) video and press `Alt + N`!
